# Mapa de sentimentos

## Para quem é

Ex-colaboradores na Etapa 2 da pesquisa e gestores de RH que analisam os resultados agregados.

## O que é

O **mapa de sentimentos** é a segunda etapa da pesquisa pós-demissão. Ex-colaboradores selecionam um ou mais sentimentos que descrevem como se sentem após a demissão. Os dados agregados alimentam indicadores de risco no dashboard do RH.

## Onde encontrar

- Pesquisa pós-demissão → Etapa 2 (`/survey`)
- Dashboard do RH → visualização agregada

## Sentimentos disponíveis

| Sentimento | Indica risco trabalhista? |
|---|---|
| Aliviado(a). Já queria sair da empresa. | Não |
| Surpreso(a). Não esperava pela demissão. | Não |
| Injustiçado(a). Minha demissão foi injusta. | **Sim** |
| Bravo(a). Não concordo em como a demissão aconteceu. | **Sim** |
| Desesperado(a). Preciso me recolocar urgente. | Não |
| Inseguro(a). Estou com a autoestima abalada com a demissão. | Não |
| Inseguro(a). Não sei quais os passos para me recolocar. | Não |
| Triste. Gostava muito do meu trabalho. | Não |
| Triste. Gostava muito da empresa. | Não |
| Triste. Gostava muito da minha equipe de trabalho. | Não |
| Indiferente. Nem feliz e nem triste. | Não |
| Indiferente. Ainda tentando entender tudo que aconteceu. | Não |

## Como funciona

### Para o ex-colaborador
1. Na Etapa 2 da pesquisa, vê pergunta: "Como você se sente?"
2. Marca um ou mais sentimentos que se aplicam
3. Avança para próxima etapa ou finaliza

### Para o RH
1. Dashboard consolida sentimentos de todos os respondentes
2. Visualiza distribuição (quantos se sentem injustiçados, surpresos, etc.)
3. Sentimentos marcados como risco trabalhista alimentam indicador específico
4. Usa insights para ações preventivas

## Indicadores derivados

| Indicador | Origem |
|---|---|
| Risco trabalhista | Sentimentos de injustiça e raiva |
| Risco de marca | Combinação de sentimentos negativos |
| Mapa visual | Distribuição de todos os sentimentos |

## Regras importantes

- Ex-colaborador deve selecionar **ao menos um** sentimento
- Pode selecionar **múltiplos** sentimentos simultaneamente
- Sentimentos de injustiça e raiva são sinalizadores de **risco trabalhista**
- Dados são agregados — RH vê visão consolidada, não respostas individuais identificáveis em excesso
