# Catálogo de serviços

## Para quem é

Ex-colaboradores, compradores e equipe interna que precisam entender os tipos de serviço oferecidos.

## O que é

O **catálogo de serviços** reúne todos os produtos disponíveis na Prepara.me — mentorias, revisões, simulador e pacotes. Os serviços são configurados pelo administrador e exibidos no site (catálogo público) e na plataforma logada (serviços do usuário).

## Onde encontrar

- **Site público:** Menu → Mentorias individuais (`/ProductList`)
- **Plataforma logada:** Painel do ex-colaborador (serviços ativos)
- **Gestão:** Menu admin → Produtos

## Tipos de serviço

Os serviços se dividem em duas categorias principais:

### Serviços agendados
Requerem **marcação de horário** com especialista:
- Mentorias 1:1 por vídeo
- Sessões de orientação de carreira
- Outras consultorias ao vivo

**Fluxo:** compra/atribuição → escolha de horário → atendimento → conclusão

### Serviços não agendados
Entregues **offline** pelo especialista, sem horário marcado:
- Revisão e reconstrução de currículo
- Análise de perfil LinkedIn
- Outras entregas documentais

**Fluxo:** compra/atribuição → envio de material → análise → entrega em até 48h

## Informações de cada serviço

| Campo | Descrição |
|---|---|
| Nome | Título completo do serviço |
| Nome resumido | Versão curta para cards e listas |
| Preço | Valor em reais (BRL) |
| Duração | Tempo estimado (mentorias) |
| Situação | Ativo ou inativo |
| Tipo | Agendado ou não agendado |
| Destaque | Pode ser marcado como "mais vendido" |

## Como os serviços chegam ao ex-colaborador

| Forma | Descrição |
|---|---|
| Compra no site | Ex-colaborador compra e serviço é vinculado à conta |
| Patrocínio empresarial | Empresa inclui serviços no pacote; admin atribui |
| Atribuição manual | Administrador adiciona serviço à conta do usuário |
| Kit Recolocação Pro | Pacote com simulador e modelo de CV |

## O que o usuário vê e pode fazer

| Quem | Ação |
|---|---|
| Visitante | Ver catálogo, preços e descrições |
| Ex-colaborador | Usar serviços ativos na conta |
| Administrador | Criar, editar, ativar/desativar produtos |
| Especialista | Entregar serviços atribuídos aos seus clientes |

## Regras importantes

- Apenas produtos **ativos** aparecem no catálogo público
- Serviços inativos permanecem visíveis para quem já possui (conforme regras de negócio)
- Cada serviço agendado consome **uma unidade** do saldo do usuário
- Preços e disponibilidade são definidos pelo administrador
