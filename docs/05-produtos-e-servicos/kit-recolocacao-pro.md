# Kit Recolocação Pro

## Para quem é

Pessoas físicas que buscam ferramentas acessíveis de recolocação profissional, sem patrocínio empresarial.

## O que é

O **Kit Recolocação Pro** é um pacote B2C com preço acessível que reúne ferramentas essenciais para quem está buscando recolocação. Combina simulador de entrevistas, apoio de respostas e modelo de currículo.

## Onde encontrar

Site → Menu **Para você** → Kit Recolocação Pro → `/KitRecolocacao`

## O que inclui

| Item | Benefício |
|---|---|
| Simulador de entrevistas | Acesso ilimitado para praticar |
| Simulador com apoio de resposta | Sugestões de como responder perguntas |
| Modelo de currículo assertivo | Template profissional para download |

## Preço e condições

- **Valor:** R$ 29,90 (pagamento único)
- **Validade:** acesso ilimitado por **3 meses**
- **Pagamento:** boleto ou cartão de crédito

## Como funciona

1. Visitante acessa a landing page do Kit Pro
2. Conhece os benefícios e o preço
3. Pode se **cadastrar diretamente** na página (nome, e-mail, CPF, senha)
4. Ou clicar em "Apenas R$ 29,90" para adicionar ao carrinho
5. Finaliza pagamento no carrinho
6. Após confirmação, acessa plataforma logada com simulador liberado

## O que o usuário vê e pode fazer

| Etapa | Ação |
|---|---|
| Landing page | Conhecer benefícios, cadastrar-se ou comprar |
| Pagamento | Pagar R$ 29,90 |
| Plataforma logada | Usar simulador, baixar modelo de CV |
| Durante 3 meses | Praticar entrevistas sem limite |

## Regras importantes

- Cadastro na página cria conta de **ex-colaborador**
- Acesso ao simulador dura **3 meses** a partir da confirmação do pagamento
- Após expiração, simulador deixa de estar disponível
- Kit Pro é independente de patrocínio empresarial
