# Painel do administrador

## Para quem é

Equipe interna da Prepara.me com perfil de administrador da plataforma.

## O que é

O painel do administrador é a **tela inicial** após login (`/platform`). Funciona como centro de comando operacional — relatórios, exportações, métricas de acesso e atalhos para gestão da plataforma.

## Onde encontrar

Após login → Painel inicial (`/platform`)

Menu lateral completo com todas as áreas de gestão (empresas, usuários, produtos, etc.).

## Componentes do painel

### Relatório de cliques
Cards com quantidade de acessos por área da plataforma, filtráveis por:
- Data inicial
- Data final

Permite entender quais funcionalidades são mais utilizadas.

### Ferramentas de dados
| Ferramenta | Função |
|---|---|
| Baixar respostas em Excel | Exporta respostas da pesquisa pós-demissão |
| Importar respostas | Carrega respostas em lote (com template) |
| Relatório visão de únicos | Consolida dados por usuário único |
| Recolocados | Atalho para relatório de recolocação |

### Filtros adicionais
Painel com filtros para refinar visualizações de respostas e dados operacionais.

## Menu lateral — áreas de gestão

| Item | Função |
|---|---|
| Empresas | Cadastro e configuração de parceiras |
| Usuários | Gestão de todas as contas |
| Funcionários | Ex-colaboradores vinculados |
| Planos de Assinaturas | Configuração de planos |
| Especialistas | Cadastro de consultores |
| Produtos | Catálogo de serviços |
| Grupos de Vídeos do Simulador | Organização de conteúdo |
| Vídeos do Simulador | Vídeos individuais |
| Adicionar Produto para Usuário | Atribuição manual |
| Mentorias Coletivas | Sessões em grupo |
| Materiais Gratuitos | Conteúdos educativos |
| Ver Produtos do Usuário | Acompanhamento de entregas |
| Ver Objetivos dos Clientes | Planilha externa |

## Como funciona

1. Administrador faz login e vê painel operacional
2. Gera relatórios por período conforme necessidade
3. Exporta/importa dados de pesquisa quando necessário
4. Acessa menu lateral para gestão específica
5. Monitora recolocação via relatório dedicado

## O que o usuário vê e pode fazer

| Ação | Onde |
|---|---|
| Gerar relatório de cliques | Painel → datas + Gerar |
| Exportar respostas | Painel → botão Excel |
| Importar respostas | Painel → botão Importar |
| Ver recolocados | Painel → Recolocados |
| Gerenciar empresas, usuários, produtos | Menu lateral |
| Atribuir serviços manualmente | Menu → Adicionar Produto |
| Configurar simulador | Menu → Vídeos do Simulador |

## Regras importantes

- Visão **global** — dados de todas as empresas
- Importação de respostas exige **template correto**
- Alterações em produtos refletem imediatamente no site e na plataforma
- Relatório de recolocados permite filtrar por empresa e período
