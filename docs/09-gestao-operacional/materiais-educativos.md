# Materiais educativos

## Para quem é

Visitantes que consomem conteúdo gratuito e administradores que publicam materiais.

## O que é

A gestão de **materiais educativos** permite à equipe Prepara.me publicar conteúdos gratuitos (e-books, guias, templates) exibidos no site público e complementares ao programa de demissão responsável.

## Onde encontrar

- **Site público:** `/MateriaisGratuitos`
- **Gestão (admin):** Menu → Materiais Gratuitos (`/materials`)

## Como funciona

### Publicação (administrador)
1. Acessa Materiais Gratuitos no menu admin
2. Cria novo material com título, descrição e arquivo
3. Material fica disponível no site público
4. Pode editar ou desativar a qualquer momento

### Consumo (visitante)
1. Acessa página de materiais gratuitos
2. Navega pela lista
3. Clica no material desejado
4. Faz download ou acessa conteúdo

## Tipos de conteúdo

| Tipo | Exemplo | Onde aparece |
|---|---|---|
| E-book | Manual de demissão responsável | Materiais gratuitos + landing B2B |
| Guia | Passos para recolocação | Materiais gratuitos |
| Template | Modelo de currículo | Materiais gratuitos |
| Artigo | Dicas de entrevista | Materiais gratuitos |

## O que o usuário vê e pode fazer

| Quem | Ação |
|---|---|
| Visitante | Ver e baixar materiais |
| Ex-colaborador | Ver e baixar materiais |
| Administrador | Criar, editar, ativar/desativar |

## Regras importantes

- Materiais são **gratuitos** — não exigem compra
- Conteúdo complementa serviços pagos, não os substitui
- Admin controla o que está publicado e disponível
- Manual de demissão também é promovido na landing B2B
