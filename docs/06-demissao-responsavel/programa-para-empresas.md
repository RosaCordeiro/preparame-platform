# Programa para empresas

## Para quem é

Empresas que desejam implementar demissão responsável e outplacement para ex-colaboradores.

## O que é

O **programa para empresas** é a oferta B2B da Prepara.me. Vai além de uma landing page — inclui contratação de serviços, configuração de patrocínio, dashboard de RH, treinamentos e materiais de apoio para gestores.

## Onde encontrar

- Site → Demissão responsável (`/demissaohumanizada`)
- Plataforma logada → Dashboard do RH (após contratação)

## Componentes do programa

| Componente | Descrição |
|---|---|
| Página de patrocínio | Landing personalizada com logo e cores da empresa |
| Pacote de serviços | Mentorias, simulador, revisão de CV — conforme contrato |
| Dashboard de RH | Indicadores e-NPS, sentimentos, riscos |
| Pesquisa pós-demissão | Feedback estruturado dos ex-colaboradores |
| Perguntas qualitativas | Customização da pesquisa pelo Admin da plataforma |
| Treinamentos | Capacitação para RH e lideranças |
| Manual/e-book | Material sobre condução de desligamentos |
| Curso de demissão | Programa educativo para gestores |

## Como funciona

1. Empresa conhece o programa na landing de Demissão Responsável
2. Entra em contato comercial e define escopo (nº de ex-colaboradores, serviços, prazo)
3. Administrador Prepara.me configura empresa na plataforma
4. Empresa recebe link de patrocínio e acesso ao dashboard de RH
5. Ex-colaboradores são convidados via link personalizado
6. RH acompanha indicadores e ajusta perguntas da pesquisa

## Benefícios para a empresa

- Redução de riscos trabalhistas e de marca empregadora
- Indicadores mensuráveis (e-NPS, mapa de sentimentos)
- Demonstração de cuidado com ex-colaboradores
- Conformidade com práticas de demissão humanizada
- Treinamento para equipes internas

## Regras importantes

- Contratação via **contato comercial**, não checkout online
- Cada empresa tem configuração **individual** (visual, serviços, perguntas)
- Dashboard depende de ex-colaboradores **responderem a pesquisa**
- Estatísticas da home (74% e-NPS, 36% risco de marca) referem-se a pesquisa Prepara.me 2023
