# Apoio ao ex-colaborador

## Para quem é

Ex-colaboradores de empresas parceiras e gestores que querem entender o que é oferecido após a demissão.

## O que é

Quando uma empresa contrata a Prepara.me, seus ex-colaboradores recebem um **pacote de apoio** para a jornada de recolocação. O conteúdo exato varia conforme o contrato, mas tipicamente inclui ferramentas práticas e acolhimento emocional.

## O que a empresa pode oferecer

| Serviço | Benefício para o ex-colaborador |
|---|---|
| Acolhimento pós-demissão | Mensagem de cuidado e orientação inicial |
| Mentorias individuais | Conversas 1:1 com especialistas de RH |
| Mentorias coletivas | Sessões em grupo com pares |
| Revisão de currículo | CV profissional reconstruído |
| Análise de LinkedIn | Orientações para perfil profissional |
| Simulador de entrevistas | Prática segura antes de entrevistas reais |
| Materiais educativos | Guias e conteúdos gratuitos |
| Pesquisa de feedback | Canal para expressar sentimentos (beneficia também o RH) |

## Como o ex-colaborador acessa

1. Recebe link de patrocínio da empresa
2. Cadastra-se na página personalizada
3. Entra na plataforma com serviços já liberados
4. Utiliza ferramentas conforme necessidade

## Experiência no painel

O ex-colaborador patrocinado vê:
- Boas-vindas com menção à empresa parceira
- Serviços disponíveis no pacote
- Convite para pesquisa pós-demissão
- Agenda para agendamentos
- Acesso ao simulador (se incluído)

## Regras importantes

- Serviços dependem do **pacote contratado** pela empresa
- Prazo de acesso pode ser limitado conforme plano
- Pesquisa pós-demissão ajuda a empresa a melhorar — resposta é voluntária mas incentivada
- Plano de aposentadoria altera serviços disponíveis
