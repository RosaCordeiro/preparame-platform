# Mentoria gratuita para empresas

## Para quem é

Empresas interessadas no programa de demissão responsável que desejam conhecer a Prepara.me antes de contratar.

## O que é

Formulário de captação na landing de **Demissão Responsável** que permite empresas solicitarem uma **mentoria gratuita** — primeiro contato com a Prepara.me para entender como o programa funciona na prática.

## Onde encontrar

Site → Demissão responsável → seção **Mentoria Gratuita**

## Como funciona

1. Gestor de RH acessa a landing de Demissão Responsável
2. Rola até a seção de mentoria gratuita
3. Preenche formulário com dados da empresa e contato
4. Equipe Prepara.me recebe solicitação
5. Retorno comercial para apresentação do programa

## O que a empresa pode esperar

- Demonstração do valor do programa
- Entendimento de como funciona patrocínio e dashboard
- Orientação sobre próximos passos para contratação
- Sem compromisso de compra imediata

## Regras importantes

- Mentoria gratuita é **captação B2B**, distinta dos serviços pagos para ex-colaboradores
- Não substitui o programa completo de patrocínio
- Resposta depende da equipe comercial da Prepara.me
- Também disponível contato via LinkedIn da fundadora (link na página)
