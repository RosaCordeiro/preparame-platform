# Demandas

Registro de **novas features e demandas** em andamento ou concluídas.

## Como iniciar

1. Diga ao Cursor: *"Nova demanda: [descrição]"*
2. O agente **Novas Demandas** (`preparame-novas-demandas`) conduz as 8 fases
3. Um arquivo será criado aqui por demanda

## Template

Copie [`template.md`](template.md) para `YYYY-MM-DD-slug.md`.
