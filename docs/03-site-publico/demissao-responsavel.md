# Demissão responsável

## Para quem é

Empresas interessadas em conduzir desligamentos de forma humanizada e oferecer apoio estruturado aos ex-colaboradores.

## O que é

A landing page **Demissão Responsável** (`/demissaohumanizada`) apresenta o programa B2B da Prepara.me. É a principal porta de entrada para empresas que desejam contratar outplacement, treinamentos e ferramentas de acompanhamento pós-demissão.

## Onde encontrar

Menu principal → **Para empresas** → Demissão responsável

## Seções da página

A landing é composta por blocos que contam a história completa do programa:

| Seção | O que apresenta |
|---|---|
| **Apresentação** | Proposta do programa de demissão responsável |
| **Mídia** | Cobertura na imprensa e reconhecimento |
| **Ajuda aos colaboradores** | Como a Prepara.me apoia quem foi desligado |
| **Empresas parceiras** | Referências e credibilidade |
| **Benefícios para empresas** | Redução de riscos, e-NPS, marca empregadora |
| **Benefícios para colaboradores** | Acolhimento, recolocação, orientação |
| **Mentoria gratuita** | Formulário para empresas solicitarem mentoria sem custo |
| **Manual de demissão** | Material educativo (e-book) sobre condução de desligamentos |
| **Curso de demissão** | Oferta de capacitação para RH e lideranças |

## Como funciona

1. Gestor de RH ou decisor acessa a landing page
2. Conhece benefícios para empresa e ex-colaborador
3. Pode solicitar mentoria gratuita, baixar manual ou conhecer o curso
4. Entra em contato comercial para contratar o programa completo
5. Após contratação, a empresa recebe página de patrocínio e acesso ao dashboard de RH

## O que o usuário vê e pode fazer

| Ação | Disponível |
|---|---|
| Conhecer o programa | Sim |
| Ver benefícios e estatísticas | Sim |
| Solicitar mentoria gratuita para empresa | Sim (formulário) |
| Baixar manual/e-book | Sim |
| Conhecer curso de demissão | Sim |
| Contratar diretamente online | Não — requer contato comercial |

## Benefícios destacados para empresas

- Indicadores de riscos trabalhistas e de marca empregadora
- Dashboard de RH com pendências e métricas
- Treinamentos para equipes
- Acompanhamento dos ex-colaboradores na recolocação

## Benefícios destacados para ex-colaboradores

- Acolhimento e acompanhamento pós-demissão
- Conversas com especialistas de RH e psicólogos
- Ferramentas de recolocação (currículo, LinkedIn, simulador)
- Materiais educativos

## Regras importantes

- A contratação B2B é feita via **contato comercial**, não checkout online
- Empresas contratantes recebem **página de patrocínio personalizada**
- O dashboard de RH só fica disponível após configuração da empresa na plataforma
