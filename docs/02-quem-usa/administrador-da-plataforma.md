# Administrador da plataforma

## Para quem é

Equipe interna da Prepara.me responsável pela operação, gestão e configuração da plataforma.

## O que é

O perfil **administrador da plataforma** tem acesso completo às ferramentas de gestão. É quem cadastra empresas parceiras, usuários, especialistas, produtos, materiais e acompanha relatórios globais de operação e recolocação.

## Onde encontrar

- **Painel inicial:** após login, em `/platform`
- **Menu lateral:** Empresas, Usuários, Funcionários, Planos, Especialistas, Produtos, Perguntas Qualitativas, Simulador, Mentorias, Materiais e mais

## Como funciona

### Painel inicial

O administrador vê um painel operacional com:

- **Relatório de cliques** — quantidade de acessos por área, filtrável por período
- **Exportação de respostas** — download de respostas da pesquisa em Excel
- **Importação de respostas** — carga de dados de pesquisa
- **Relatório de usuários únicos** — visão consolidada
- **Acesso ao relatório de recolocados** — métricas de recolocação

### Áreas de gestão

| Área | Função |
|---|---|
| Empresas | Cadastrar e configurar empresas parceiras (logo, cores, patrocínio) |
| Usuários | Criar e gerenciar contas de todos os perfis |
| Funcionários | Vincular ex-colaboradores às empresas |
| Especialistas | Cadastrar consultores de RH |
| Produtos | Manter catálogo de serviços (preço, tipo, status) |
| Perguntas qualitativas | Cadastrar perguntas personalizadas da pesquisa por empresa |
| Planos de assinatura | Configurar planos disponíveis |
| Simulador | Gerenciar grupos e vídeos do simulador de entrevistas |
| Mentorias coletivas | Criar e editar sessões em grupo |
| Materiais gratuitos | Publicar conteúdos educativos |
| Adicionar produto para usuário | Atribuir serviços manualmente a um ex-colaborador |

## O que o usuário vê e pode fazer

| Ação | Onde |
|---|---|
| Gerar relatórios por período | Painel inicial |
| Exportar/importar respostas de pesquisa | Painel inicial |
| Cadastrar empresas e configurar patrocínio | Menu → Empresas |
| Gerenciar todos os usuários | Menu → Usuários |
| Importar funcionários em lote | Menu → Funcionários |
| Manter catálogo de produtos | Menu → Produtos |
| Cadastrar perguntas qualitativas por empresa | Menu → Perguntas Qualitativas |
| Atribuir serviços manualmente | Menu → Adicionar Produto para Usuário |
| Acompanhar entregas de especialistas | Menu → Ver Produtos do Usuário |
| Ver métricas de recolocação | Relatório de Recolocados |
| Consultar objetivos dos clientes | Link externo → planilha Google |

## Regras importantes

- O administrador tem visão **global** — enxerga dados de todas as empresas
- Alterações em produtos afetam imediatamente o catálogo do site e a plataforma
- Atribuição manual de produtos é usada para patrocínios e casos especiais
- Importação de respostas deve seguir o template disponibilizado pela plataforma
