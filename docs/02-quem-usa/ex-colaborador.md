# Ex-colaborador

## Para quem é

Pessoas demitidas ou em processo de recolocação que utilizam a plataforma — seja por patrocínio empresarial ou compra individual.

## O que é

O perfil **ex-colaborador** é o usuário final principal da Prepara.me. É quem recebeu apoio da empresa após a demissão ou quem contratou serviços por conta própria. Na plataforma, esse perfil acessa ferramentas de recolocação, acompanha agendamentos e responde pesquisas de feedback.

## Onde encontrar

- **Painel inicial:** após login, em `/platform`
- **Menu lateral:** Simulador de entrevistas, Meus Pedidos
- **Perfil:** ícone de usuário no cabeçalho → Meu perfil

## Como funciona

### Ao entrar na plataforma

O ex-colaborador vê um painel com:

1. **Card de boas-vindas** — mensagem personalizada, especialmente para quem veio por patrocínio empresarial
2. **Agenda** — próximos compromissos (mentorias agendadas, sessões coletivas)
3. **Pesquisa pós-demissão** — convite para responder NPS e mapa de sentimentos (se ainda não respondeu)
4. **Simulador de entrevistas** — acesso rápido se o serviço estiver disponível
5. **Perguntas frequentes em entrevistas** — dicas de preparação
6. **Mentorias coletivas** — calendário de sessões em grupo (quando disponível)

### Serviços disponíveis

Depende de como o ex-colaborador chegou à plataforma:

| Origem | Serviços típicos |
|---|---|
| Patrocínio empresarial | Pacote definido pela empresa (mentorias, simulador, revisão de CV) |
| Compra individual | Serviços adquiridos no site (mentorias, Kit Pro, revisão) |
| Atribuição manual | Serviços adicionados pelo administrador |

## O que o usuário vê e pode fazer

| Ação | Onde |
|---|---|
| Ver agenda de compromissos | Painel inicial |
| Agendar mentorias disponíveis | Painel → serviços com saldo |
| Responder pesquisa pós-demissão | Painel ou `/survey` |
| Usar simulador de entrevistas | Menu → Simulador de entrevistas |
| Ver e baixar pedidos | Menu → Meus Pedidos |
| Trocar horário de mentoria coletiva | Painel → calendário de mentorias |
| Atualizar dados pessoais | Meu perfil |
| Enviar currículo para revisão | Dentro do fluxo do serviço contratado |
| Acompanhar status de entrega | Meus Pedidos / painel de serviços |

## Regras importantes

- A **pesquisa pós-demissão só pode ser respondida uma vez** — após finalizar, não é possível refazer
- Usuários em **plano de aposentadoria** não veem a pesquisa nem algumas mensagens de boas-vindas
- O simulador de entrevistas exige que o serviço esteja **ativo e dentro do prazo de acesso**
- Serviços agendados (mentorias) exigem escolha de horário com especialista disponível
- Revisão de currículo/LinkedIn tem prazo de entrega de até **48 horas**
